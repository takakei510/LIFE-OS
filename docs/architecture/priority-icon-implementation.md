# 優先4モチーフと既存素材の割り当て

Tracks: #64 / Depends on: #63 / PR: #65 / 本番未反映

## 採用内容

2026-11-04、デザイン成果物の共有後にユーザーから実装指示を受け、優先4モチーフ25件と既存素材レビュー84件を採用する。原本は`docs/design/priority-icons-v1`。SPEC/manifestは受領時のデザイン原本を保持し、この文書をアプリでの採用範囲とする。

|範囲|件数|処理|
|---|---:|---|
|life-code|12|コード・データ操作の実績IDへ割り当て|
|life-rest|6|休息・感覚の切り替えの実績IDへ割り当て|
|life-video|4|映像視聴の実績IDへ割り当て|
|life-ai|3|AIとの対話・比較の実績IDへ割り当て|
|既存素材レビュー|84|推奨されたモチーフを個別IDへ割り当て|

`achievement-motifs.ts`はIDとモチーフだけを持ち、名称・条件・Tier・XP・保存データを複製しない。109件は一意で、既存の個別指定3件とは重複しない。名前やDomainから推測する実行時処理は追加しない。

## 既存素材の扱い

- life-bodyは、採用した11実績に限り名前横とバッジ中央へ用途を拡張する。当初のカテゴリ専用仕様からの承認済み追加。原本pathは維持する。
- life-growthはカテゴリ専用のまま。「狙いを持った一手」はlife-researchを使用する。
- 「夜の灯り替え」はlife-windowを使用する。
- 洗濯・机整理の2件は、既存NeoIcon/homeのpathをそのまま別symbolのlife-homeへ流用する。ナビ本体は変更しない。原本と流用元は`docs/design/home-motif-reuse`に記録する。
- 既存Domainの対応表、Categoryの完全一致ルールは変更しない。

## 表示と名前の境界

16/20pxはsmall、24px以上と48/64pxバッジ中央は標準symbolを使用する。AIのみsmallで端子を省略する。SVGは原本どおり24単位・線幅1.6・丸い線端・fillなし。通常色#A8BBD2、バッジ中央は優先仕様の#E6F2FFに揃える。Tier色は枠とTier文字のみ。

モチーフ選択は、109件のID対応→既存の個別指定→既存Domain→generalの順。既存の名前表示は引き続き111件のID＋一致接頭辞だけを処理する。モチーフの登録は絵文字を削除する条件にしない。改名された名前や名前途中の絵文字は保持し、同名の「コードの中を歩く」2件も別IDとして扱う。

未知IDは従来のDomainフォールバックを使用する。未制作のgame/device/clothing/shopping/board-gameの11実績と「はじめの一歩」はgeneralを維持する。調査時点の262件では共通マーク121→12件、専用モチーフ141→250件の見込み。
