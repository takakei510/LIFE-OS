# 探索案内人（Issue #53）

気分・時間・環境から既存の実績と自由クエストを提案する。新規実績作成・自動解除・自動受注・会話履歴保存は行わない。

## 境界

UI → POST `/api/guide` → Application Service → 専用Notion Repository。
Notion側のNotes / Descriptionにある探索メタデータを正規化。既存DBの項目は変更しない。実績はActive・Visible・未解除、クエストはActive・Availableだけ取得。冒険ログ、写真、称号、PLAYER記録は読み込まない。

600文字以下の相談と選択条件をサーバーで検証。明示的な時間・環境・出費・人数・気力条件は不明値を除外してからAIへ渡す。会得系の時間は一回の練習時間として扱い、会得までの時間とは区別する。

候補は完全一致の条件を重複除去し、話題とカテゴリの分散を考慮して最大60件。AIはID・理由・最初の一歩を0〜3件返す。IDと重複を再検証し、名前・解除条件・リンクはサーバーの登録データから表示。登録済みの最初の一歩を優先。関連実績とクエストの二重提案も拒否する。自由文中の追加条件はAIが考慮するが、意味の解釈には限界があるため、必須の条件はフォーム選択を推奨する。

## 個人情報

相談文と候補の説明・条件をVercel AI Gatewayと選択モデルの提供元へ送信。アプリ側のDB・localStorage・ログへ相談を保存しない。提供元の保持方針は別途適用。生の例外・プロンプトをログへ出さない。AIに書込ツールを渡さない。

## 無料枠での開始

本人は無料クレジットのみ許可。有料購入・自動チャージ・カード入力を代行しない。カード確認は本人が行う。

- `AI_GATEWAY_MODEL`: 現行モデル一覧で確認した対応モデルID。
- `GUIDE_ENABLED=true`: 公開スイッチ。
- `GUIDE_FREE_CREDITS_VERIFIED=true`: 無料残高、購入済みクレジットなし、自動チャージ無効、プロジェクト予算を確認した場合のみ設定。
- 認証はVercel OIDC。既存Vercel Deployment Protectionを維持し、未保護の公開環境では有効にしない。
- 有効化時にGateway側のプロジェクト予算を無料残高より低く設定。予算はsoft capであり、単独で無料を保証するものではない。購入・自動チャージ無効と併用する。
- 残高APIを毎回確認し、残高0.05ドル未満や照会失敗時は送信しない。残高の種類はAPIだけでは識別できないため、管理者確認フラグも必要。
- AI呼出しは30秒、最大1800出力トークン、自動リトライなし。候補0件時はAIを呼ばない。
- 20秒のローカルcooldownは多重操作の補助に限る。分散レート制限や金額制限とは扱わない。金額はGateway側で制御。

無料枠確認前でも画面を表示できるが、送信ボタンとAPIは無効。失敗時に架空の提案やLLM風の固定回答を返さない。

## 検証

`npm run test:guide --workspace apps/web`、TypeScript、production build。保護されたpreviewで初期画面・モバイル幅・相談→提案→実績詳細／クエスト絞り込みを確認。実環境でのAI呼出しは無料枠を確認後にのみ実施。
