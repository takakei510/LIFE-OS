# LIFE OS Web v0.2.0

リリース日：2026-07-21

## 概要

Version 0.2では、Version 0で完成したNotion連携Webアプリを、スマホから日常的に遊びやすい形へ改善しました。

## 追加・改善

### モバイル操作

- スマホ用の固定下部ナビゲーションを追加
- HOME・実績・クエスト・称号・Statusへ常時移動可能
- 実績画面の主要表記を日本語へ統一

### 実績ライブラリ

- 通常実績は未解除でも名前・Flavor Text・条件を表示
- Hidden実績だけ秘密表示を継続
- 実績名、Flavor Text、達成条件、カテゴリ、Tier、Domainの横断検索を追加
- カテゴリ・Tier・解除状態フィルターとの併用に対応

### HOME

- 最近解除した実績を最大3件表示
- 解除日、カテゴリ、獲得XP、詳細画面への導線を追加

### アプリ体験

- PWAとしてスマホのホーム画面へ追加可能
- standalone表示と専用アイコンに対応
- Notion読み込み中のスケルトン表示を追加
- エラー時の再読み込み画面とHOMEへの復帰導線を追加

## データ管理

新しい管理元は追加していません。実績・称号・クエスト・Statusは引き続き各Notion DBを唯一の管理元とし、Webアプリは表示のみを担当します。

## 既知の制限

- WebアプリからNotionへの書き込みには未対応
- オフライン動作には未対応
- 称号の装備変更はNotion側で行う
- クエストの受注・完了操作はNotion側で行う

## 次の候補

- Webから実績解除を記録する安全な書き込み機能
- クエスト受注・完了操作
- 称号装備切り替え
- 図鑑・コレクション機能
- 今日のおすすめ体験
