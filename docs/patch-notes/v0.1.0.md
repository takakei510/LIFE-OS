# LIFE OS v0.1.0

Released: 2026-07-21

## Overview

LIFE OSのWeb版Version 0を初めて本番公開したリリース。
Notionを唯一のセーブデータとして利用し、人生で触れた体験をゲーム画面として表示する。

## Added

- Notion読み取り同期
- PLAYER CARD
- 実績ライブラリ
- 実績詳細画面
- クエストボード
- 称号コレクション
- PLAYER STATUS
- Achievement Unlocked演出
- Category・Tier・状態フィルター
- Hidden実績の非公開ルール
- 通常実績は未解除でも内容を表示
- スマートフォン対応
- GitHub Actionsによる型チェック・ビルド確認
- Vercel Productionデプロイ

## Security

- NotionトークンはVercel環境変数で管理
- クライアントへ秘密情報を公開しない
- Next.jsを脆弱性修正版へ更新

## Data Flow

```text
Notion
  ↓ read-only
Next.js Server
  ↓
LIFE OS Web UI
```

## Production

- https://life-os-web-m3ds.vercel.app

## Known Limitations

- Notionへの書き込みはWebアプリから行わない
- 称号装備変更はNotion側で行う
- クエストの受注・完了操作はNotion側で行う
- 実績解除演出の既読状態はブラウザごとに保存される

## Next

Version 0.2では、スマホ下部ナビゲーション、検索、PWA対応、最近解除した実績一覧を候補とする。
