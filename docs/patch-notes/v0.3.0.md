# LIFE OS Web v0.3.0

リリース日：2026-07-21

## 概要

Version 0.3では、Notionに保存された記録を探しやすくし、最近触れた世界と次に触れられる世界を眺められるようにしました。

## 追加・改善

### クエスト

- 名前・説明・達成条件・カテゴリ・種類・状態・XPの横断検索
- 種類と状態による絞り込み
- 状態表示を日本語化

### 称号

- 名前・説明・Tierの検索
- 装備中・取得済み・未取得による絞り込み
- Tierによる絞り込み
- 未取得称号の秘密表示を維持

### Status

- カテゴリごとの実績解除数、総数、獲得XPを表示
- 冒険の広がりを進捗バーで表示
- カテゴリから実績一覧への導線を追加

### HOME

- 実績解除とクエスト完了を統合した「最近の冒険ログ」を追加
- 未解除の通常実績から毎日3件を選ぶ「今日の探索候補」を追加
- Hidden / Secret実績は探索候補から除外

## データ管理

新しい管理元は追加していません。Achievements、Titles、Quests、Statusの各Notion DBを唯一の管理元とし、検索・集計・提案はWebアプリ側で自動生成します。

## 既知の制限

- WebアプリからNotionへの書き込みには未対応
- クエスト受注・完了、称号装備、実績解除の更新はNotion側で行う
- オフライン動作には未対応

## 次のフェーズ

Version 0.4では、安全なNotion書き込み機能を設計し、Webアプリからの実績解除・クエスト操作・称号装備を段階的に検討します。
