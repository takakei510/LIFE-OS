# Life OS 独自アイコン仕様 v1.0

独立したデザイン提案。アプリ、Notion、分類、実績名、解除条件への変更はありません。既存A2-4 Stellar CompassロゴとナビSVGは維持します。

## 形状とサイズ

- viewBox="0 0 24 24"。線幅1.6、round cap / round join、fill="none"、currentColor。ナビの既存ルールに揃えています。
- 基本座標は3〜21。線外端は2.2〜21.8。アイコン外側に最低2 CSS px、文字との間は6〜8 px。タップ可能な場合はアイコンを拡大せず44px以上の操作領域を確保。
- 16 / 20pxは `-small.svg`、24px以上は標準SVG。線幅はviewBoxと比例して16px時1.07、20px時1.33、24px時1.6 CSS px。16px未満は使用しない。
- 小サイズでは発見の内部の短線、窓の光線、自然の雪稜、カフェの2本目の湯気、料理の2本目の湯気、研究の液体内の短線を省略。他は同形。
- バッジは64単位。既存の六角形の外形を維持し、外枠2、内枠1（opacity .24）。内部のモチーフは32×32、x=16 y=16。48px時は全体を0.75倍。中央モチーフの実寸24 / 32px、線幅1.6 / 2.13px。
- Beginnerのバッジ比較は形状検証のみ。ランクを実績Tier扱いする提案ではありません。

## 色と情報の強弱

背景 #0B1220、面 #111B2E。通常アイコン #A8BBD2、強調するモチーフ #E6F2FF。Primary #00D9F5、Accent #A78BFA、Light Blue #7CE1FF は既存UIのトークンとして維持し、全アイコンに広げない。単色線画。影・発光・立体装飾なし。

Tierは星を追加しない。六角枠とTier名だけをTier色にし、モチーフは中立色に統一。Common #BAC8DC、Uncommon #00D9F5、Rare #A78BFA、Epic #FFD166、Legendary #FF5C7A。5色は既存ブランド仕様に合わせた値。必ず英語Tier名を併記する。未設定・未知のTierは #A8BBD2 と「Tier未設定」を使用し、Commonに補完しない。

## 適用とデータ境界

実績名横は16 / 20px、詳細見出しは24px、一覧バッジは48px、詳細バッジは64pxを推奨。名称とバッジを同時表示しても同じモチーフIDを使う。

既存のCafe→life-cafe、Photography→life-photo、Nature→life-natureは継承。他の対応は既存の分類IDを確認して表示専用マップに追加する。日本語の表示名から分類を推測しない。複数分類なら登録順の最初の対応モチーフ、対応なしはlife-general。分類そのものを追加・改名しない。

文字列内の絵文字を正規表現などで一律削除しない。アプリが別要素として挿入する装飾絵文字だけをSVGへ置換する。名前に含まれるものを表示上で差し替える必要がある場合は、ユーザーが確認した実績IDと装飾接頭辞の対応に限定し、元の名前は保持する。

Beginnerはlife-rank-beginnerを20 / 24pxで表示し、色は #A8BBD2。将来は同じグリッド・線幅・余白と「ラベル＋1つの輪郭モチーフ」を継承。大小、金属色、王冠、星の個数で能力序列を強調しない。新しい名前・条件・成長段階は未定義。

## アクセシビリティ・組み込み

名称が隣にあるSVGは aria-hidden="true" focusable="false"。単独の場合は role="img" と日本語 aria-label を与える。色に加えて実績名・Tier名を維持。小サイズを情報の唯一の手がかりにしない。

単体SVGは編集可能なpath / circle / ellipse / rectで構成。JS・外部フォント・画像依存なし。`currentColor`はインラインSVGまたはsymbol/useで継承する。img要素では親のCSS色が内部に伝わらないため、実装時はインラインかspriteを使う。spriteの各IDには標準版と-small版があり、同一文書へ一度だけ読み込む。

ボード・見本の実績名は説明用の架空文言です。ボードの文字はシステムフォント依存ですが、アイコン自体にテキストは使っていません。編集時に外部サービスは不要です。
